# Pic ’n Tear Receipt Photobooth Releases

This repository distributes official Pic ’n Tear Receipt Photobooth production releases.

The application source code is not contained here. Production releases are distributed as signed Android APKs through the official GitHub release assets.

Future release metadata will be provided through `update.json`. Production APKs use the naming convention:

```text
PicnTear-Receipt-Photobooth-v<versionName>.apk
```

Each metadata entry includes a SHA-256 digest identifying the exact APK bytes for that release.

Customers should obtain releases only from this official repository and its GitHub release assets.
